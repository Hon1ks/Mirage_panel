# Установка Mirage на сервер

Панель Mirage — веб-интерфейс для Claude Code: чат с Claude, файлы, терминал, календарь — из браузера и с телефона.
Ставится на свой сервер (VPS) и работает через вашу подписку Claude.

Почти всё делают три скрипта из папки [`scripts/server/`](../scripts/server):

| Скрипт | Что делает |
|---|---|
| `install.sh` | ставит всё нужное, собирает панель, создаёт службу — **одна команда** |
| `https.sh` | открывает панель в интернет по HTTPS со своим доменом |
| `update.sh` | обновляет панель до свежей версии из репозитория |

Вручную остаются только три шага, которые нельзя автоматизировать: вход в аккаунт Claude, регистрация владельца
панели и A-запись домена у регистратора.

---

## Что нужно

- **Сервер** с Ubuntu 22.04 / 24.04 или Debian 12, от **2 ГБ** памяти и 10 ГБ диска. Доступ по SSH с правами `sudo`.
- **Подписка Claude** (Pro или Max) — или ключ API Anthropic.
- **Домен** (например, `panel.mysite.ru`) — если панель нужна из интернета, а не только через SSH-туннель.

---

## Шаг 1. Установка — одна команда

Зайдите на сервер по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Hon1ks/Mirage_panel/main/scripts/server/install.sh -o install.sh
sudo bash install.sh --tz Europe/Moscow
```

`--tz` — ваш часовой пояс (необязательно; список — `timedatectl list-timezones`). Другие параметры — `sudo bash install.sh --help`.

Скрипт идёт 15–25 минут (почти всё время — сборка) и сам:

1. ставит git, сборочные пакеты и **Node.js 22**;
2. добавляет **swap 2 ГБ**, если памяти мало для сборки;
3. создаёт пользователя **`mirage`** — панель работает от него, **не от root**;
4. ставит этому пользователю **Claude Code**;
5. скачивает панель в `/home/mirage/mirage-panel`, пишет `.env` и собирает;
6. создаёт и запускает службу **`mirage`** (systemd): автозапуск после перезагрузки, перезапуск при сбое.

Панель слушает только `127.0.0.1:3001` — из интернета её пока не видно. Это нарочно, см. шаг 3.

Повторный запуск безопасен: уже сделанное пропускается.

## Шаг 2. Вход в Claude

```bash
sudo -iu mirage claude
```

Откроется Claude Code. Наберите `/login`, откройте ссылку в браузере, войдите в свой аккаунт Claude, вставьте код
обратно в терминал. Потом `/exit`.

> Войти можно и позже, прямо из панели, — но удобнее сразу.

## Шаг 3. Регистрация владельца — через SSH-туннель

⚠️ **Первый, кто откроет панель, становится её владельцем.** Других пользователей у панели нет. Поэтому
регистрируйтесь до того, как открыть панель в интернет, — через туннель.

На **своём компьютере** (не на сервере):

```bash
ssh -L 3001:127.0.0.1:3001 ваш-логин@IP-сервера
```

Пока это окно открыто, откройте в браузере **http://127.0.0.1:3001**, придумайте логин и пароль (от 12 символов) и
пройдите мастер первого запуска.

Если панель нужна только вам и только через туннель — на этом всё.

## Шаг 4. Доступ из интернета по HTTPS

1. У регистратора домена добавьте **A-запись**: `panel.mysite.ru` → IP сервера. Подождите 5–30 минут.
2. На сервере:

```bash
sudo bash /home/mirage/mirage-panel/scripts/server/https.sh --domain panel.mysite.ru
```

Скрипт:

- **проверяет, что владелец уже зарегистрирован** — иначе откажется (защита от чужой регистрации);
- проверяет, что домен смотрит на этот сервер;
- ставит **Caddy** — он сам получает и продлевает сертификат Let's Encrypt;
- добавляет сайт (чужие сайты в Caddyfile не трогает, копия старого файла остаётся рядом);
- открывает порты 80 и 443, если включён файрвол `ufw`;
- прописывает адрес панели для ссылок (Telegram) и проверяет, что `https://panel.mysite.ru` открывается.

## Шаг 5. Сразу после

- **Включите двухфакторную защиту:** Настройки → Аккаунт. Панель даёт полный доступ к серверу — пароля мало.
- Добавьте проект: любая папка в `/home/mirage`. Проекты, где вы уже работали с Claude Code в терминале,
  появятся сами.

---

## Обновление

```bash
sudo bash /home/mirage/mirage-panel/scripts/server/update.sh
```

Берёт новые коммиты, собирает и перезапускает панель. Если сборка не удалась — возвращает прежнюю версию, и панель
продолжает работать как была. Кнопка «Обновить» внутри панели специально отключена: обновления — только этим скриптом.

## Полезные команды

| Задача | Команда |
|---|---|
| Состояние службы | `systemctl status mirage` |
| Логи в реальном времени | `journalctl -u mirage -f` |
| Перезапуск | `sudo systemctl restart mirage` |
| Что видит панель (версия, база, настройки) | `sudo -iu mirage bash -c 'cd mirage-panel && npm run mirage -- status'` |
| **Забыли пароль** | `sudo -iu mirage bash -c 'cd mirage-panel && npm run mirage -- passwd'` |

Пароль через интернет не сбрасывается — только так, на сервере. Двухфакторная защита при этом остаётся.

## Настройки

Файл `/home/mirage/mirage-panel/.env`. Все возможные настройки с пояснениями — в
[`.env.example`](../.env.example): часовой пояс, Telegram-бот для уведомлений и подтверждений, голосовой ввод
(Yandex SpeechKit), Google Календарь, счётчик лимитов подписки. Всё необязательно.

После правки: `sudo systemctl restart mirage`.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Сборка падает с `heap out of memory` | мало памяти: проверьте swap (`free -m`), повторите `install.sh` |
| `панель не отвечает на 127.0.0.1:3001` | `journalctl -u mirage -n 50` — там причина |
| `https.sh`: «владелец ещё не зарегистрирован» | сначала шаг 3 (туннель и регистрация) |
| `https.sh`: «домен пока не находится» | A-запись ещё не разошлась — подождите и повторите |
| Сайт не открывается по HTTPS | `journalctl -u caddy -n 30`; порты 80/443 открыты у хостера? |
| Claude в панели «не вошёл» | шаг 2 ещё раз: `sudo -iu mirage claude` → `/login` |

## Удаление

```bash
sudo systemctl disable --now mirage
sudo rm /etc/systemd/system/mirage.service && sudo systemctl daemon-reload
sudo userdel -r mirage            # удалит панель, её базу и настройки Claude этого пользователя
```

Если ставили HTTPS — удалите блок `# >>> mirage …` из `/etc/caddy/Caddyfile` и `sudo systemctl reload caddy`.
